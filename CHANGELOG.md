# Changelog

## 0.1.0 — 2026-10-10

First installable version (local mode, data on the device).

- Command Center: ATLAS greeting from your data, 24h timeline ring with a live "now" hand, plate ring, next-up countdown, deadline board (red < 24h, amber < 72h, pulsing URGENT tag), Noor small step, stats strip
- Barbell: four configurable plates (gym trained / rest / skipped-with-reason, minutes + notes), morning routine, slip toggle, won-day logic and streak, 14-day strip, DAY SECURED animation
- Tasks: quick capture, due dates, areas, grouped Overdue / Today / This week / Later / Inbox / Done
- Money: 5-second expense entry, daily budget threat bar, month total
- Iron-vibe HUD design: red / gold / cyan, hex grid, rotating rings, flicker-in panels, calm mode, reduced-motion support
- Optional sound: original suit-up power-on and Ryan voice greeting with a speech-reactive ring (off by default)
- PWA: installable on iPhone, works offline; JSON export / import backup
- CI: lint, type-check, tests, build and deploy to GitHub Pages
